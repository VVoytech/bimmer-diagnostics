## Bimmer Diagnostics

Simple project for reading BMW fault codes and monitoring live logs using an OBD-II / D-CAN interface.

### Features
- Read and clear diagnostic trouble codes (DTCs)
- View real-time sensor and ECU data
- Basic live logging for troubleshooting

### Requirements
- BMW-compatible OBD-II / D-CAN cable or adapter
- Supported OBD-II interface and drivers

### Goal
Provide a lightweight tool for quick BMW diagnostics and live data checks.
